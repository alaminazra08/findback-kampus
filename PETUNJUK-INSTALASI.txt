FINDBACK KAMPUS - PATCH ANIMASI LONCENG ADMIN

Tujuan:
- Menyamakan animasi lonceng admin dengan user.
- Getar singkat ketika kursor diarahkan dan ketika tombol diklik.
- Getar dua kali ketika notifikasi baru terdeteksi.
- Mempertahankan badge jumlah notifikasi belum dibaca.
- Menghormati pengaturan Reduce Motion perangkat.

File patch:
- public/css/admin/admin-dashboard.css
- public/js/shared/notification-bell-motion.js
- resources/views/admin/partials/notification-bell.blade.php
- resources/views/admin/layouts/items.blade.php

Pemasangan:
1. Cadangkan folder proyek terlebih dahulu.
2. Ekstrak ZIP ke root proyek FindBack Kampus (folder yang berisi file artisan), gabungkan folder yang ada.
3. Jalankan perintah:
   php artisan view:clear
   php artisan optimize:clear
4. Buka dashboard admin, tekan Ctrl + F5, lalu uji hover, klik, dan notifikasi baru.

Patch ini tidak menyertakan .env, database, vendor, node_modules, atau .git.
