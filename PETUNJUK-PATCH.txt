PATCH FINDBACK KAMPUS - NOTIFIKASI EMPTY STATE

Perubahan:
- Menghapus tombol "Laporkan barang hilang" dari empty state halaman Notifikasi.
- Mempertahankan tombol utama "Buka aktivitas saya".
- Tidak mengubah halaman/form laporan barang hilang yang diakses dari menu lain.
- Tidak mengubah database, route, controller, atau fitur notifikasi lainnya.

Pemasangan:
1. Ekstrak ZIP ini ke folder proyek Laravel:
   C:\xampp\htdocs\findback-kampus
2. Jalankan:
   cd /d C:\xampp\htdocs\findback-kampus
   php artisan view:clear
3. Muat ulang browser dengan Ctrl + F5.

Catatan:
File patch menggunakan struktur relatif resources/views/... sehingga menimpa tampilan Notifikasi yang aktif.
