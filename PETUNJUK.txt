FINDBACK KAMPUS - DROPDOWN 4 NOTIFIKASI TERBARU TANPA SCROLL

Perubahan terbatas (dari ZIP findback-kampus(3).zip):
- notification-bell.blade.php: hanya 4 notifikasi terbaru.
- admin-dashboard.css: panel tidak lagi dipaksa scroll pada viewport normal.
- items.blade.php: versi CSS diperbarui agar Chrome memuat gaya terbaru.
- Pada layar sangat pendek (<651px), scroll tetap diizinkan untuk menjaga akses.
- Footer "Lihat semua notifikasi" tetap ada; route dan database tidak diubah.

PENTING: patch ini berasal dari ZIP terakhir yang diunggah. Bila file terkait
sudah diedit lagi di PC setelah pembuatan ZIP, bandingkan dahulu sebelum ekstrak.

Instal CMD dari folder project:
  cd /d C:\xampp\htdocs\findback-kampus
  mkdir "%TEMP%\findback-notif-4-backup"
  copy resources\views\admin\partials\notification-bell.blade.php "%TEMP%\findback-notif-4-backup\"
  copy public\css\admin\admin-dashboard.css "%TEMP%\findback-notif-4-backup\"
  copy resources\views\admin\layouts\items.blade.php "%TEMP%\findback-notif-4-backup\"
  tar -xf "%USERPROFILE%\Downloads\findback-notifikasi-4-terbaru-tanpa-scroll.zip" -C .
  php artisan optimize:clear

Buka dashboard dan tekan Ctrl+F5 untuk refresh cache browser.
