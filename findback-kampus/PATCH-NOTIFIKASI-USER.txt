PATCH NOTIFIKASI USER — PAGINATION & HOVER

Isi patch:
- resources/views/user/notifications/index.blade.php

Perubahan:
1. Pagination selalu rata tengah pada desktop dan mobile.
2. Hover pada baris notifikasi tidak lagi mengubah warna/menimbulkan kesan penanda.
3. Warna belum dibaca dan sudah dibaca tetap ditentukan oleh status notifikasi.
4. Posisi scroll dipertahankan ketika berpindah halaman pagination.

Cara pemasangan:
1. Tutup tab aplikasi atau biarkan terminal Laravel tetap berjalan.
2. Jalankan perintah backup terlebih dahulu.
3. Ekstrak ZIP ke folder root proyek C:\xampp\htdocs\findback-kampus.
4. Bersihkan cache view.
5. Refresh browser dengan Ctrl + F5.

Perintah CMD:
cd /d C:\xampp\htdocs\findback-kampus
copy /Y "resources\views\user\notifications\index.blade.php" "%USERPROFILE%\Downloads\notification-user-before-pagination.blade.php"
tar -xf "%USERPROFILE%\Downloads\FindBack-Patch-Notifikasi-User-Pagination-Scroll.zip" -C .
php artisan view:clear

Catatan:
Jalankan setiap perintah setelah perintah sebelumnya selesai. Perintah copy /Y mencegah prompt konfirmasi overwrite.
