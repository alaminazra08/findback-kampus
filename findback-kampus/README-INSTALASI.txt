FindBack Kampus - Search input white-surface consistency patch

Isi:
- public/css/admin/search-input-consistency.css
- resources/views/admin/layouts/items.blade.php

Instalasi (CMD Windows, dari folder project):
cd /d C:\xampp\htdocs\findback-kampus
tar -xf "%USERPROFILE%\Downloads\findback-search-white-input-v6.zip" -C "C:\xampp\htdocs\findback-kampus"
php artisan view:clear

Setelah itu refresh browser dengan Ctrl+F5.
Patch ini tidak mengubah database, route, controller, atau data aplikasi.
